DM Bootcamp — Zero to Hero in Data Mining

Seven modules built from ~450 slides of lecture material, rewritten as a real tutorial: motivation before mechanism, plain-English intuition, one fully-worked numeric example per major concept — plus a summary of the professor's own sprint exercises and solutions at the end of each module.

What data mining is, the project lifecycle, data representation, and the vocabulary (data types, task types) the rest of the bootcamp assumes.

Definitions · Lifecycle · Data types Module 2

The Data Mining Pipeline

Preprocessing end to end — encoding, missing data, imbalance, scaling — plus PCA, t-SNE, evaluation metrics, and model selection.

Preprocessing · PCA/t-SNE · Metrics Module 3

Classification

Decision trees (entropy, information gain, pruning), Random Forests, AdaBoost, and a first pass at explainability.

Trees · Random Forest · AdaBoost Module 4

K-Means · Elbow method · Gap statistic Module 5

Gradient descent · Backprop · Optimizers Module 6

Tokenization · Decoding · RAG Module 7
