High-Level Overview

Gradient Descent (How models learn)

Imagine you are blindfolded on top of a mountain, and you need to get to the lowest valley (the lowest "Cost" or "Error"). You feel the slope with your feet, and take a step downhill. You repeat this until it's completely flat. This is exactly how machine learning models adjust their internal weights to find the best fit!

1

Linear vs Logistic Regression

Both are forms of regression, but they have completely different use cases.

Linear Regression

Predicts a continuous number. Example: Predicting the exact price of a house, or predicting someone's exact salary.

Logistic Regression

Predicts a probability between 0 and 1, which is used for classification. Example: Predicting if a passenger survived the Titanic (1) or not (0).

Since we are predicting Titanic survival, we must use Logistic Regression. (If there are more than 2 classes, like predicting if a fruit is an Apple, Banana, or Orange, we use Multiclass Logistic Regression, which operates the exact same way!).

💡
Teacher's Note: The Sigmoid Function (S-Curve)

You might wonder: how does Logistic Regression force the answer to be exactly between 0 and 1?

It uses the Sigmoid Function. Imagine a straight, diagonal line (Linear Regression) going from negative infinity to positive infinity. The Sigmoid function grabs both ends of that straight line and bends them down flat, creating an "S" shape that never goes below 0 and never goes above 1. It acts as an ultimate mathematical squasher!

Training the Model

Let's build the model using the preprocessed Titanic data from the previous page.

The Code Reality

from sklearn.linear_model import LogisticRegression

# 1. Initialize the model. 
# The exercise asks for a regularization parameter C=0.0005 to prevent overfitting.
# random_state=0 ensures we get the exact same results every time.
model = LogisticRegression(C=0.0005, random_state=0)

# 2. Train the model on the training data! (The blindfolded walk down the hill)
model.fit(X_train_scaled, y_train)

# 3. Generate predictions on the locked-away test set
y_pred = model.predict(X_test_scaled)

# We can also get the raw probabilities (e.g., 85% chance of survival)
y_pred_proba = model.predict_proba(X_test_scaled)[:, 1]

Evaluation & Bias vs Variance

To see if our model is any good (and if it is overfitting), we must evaluate it using metrics.

Accuracy

Total correct predictions divided by total predictions.

ROC-AUC

Measures how well the model separates the classes based on probabilities. 1.0 is a perfect score, 0.5 is literally random guessing.

💡
Teacher's Note: When Accuracy is a Liar

Imagine a rare disease that only 1% of the population has. If I build a completely useless model that just hardcodes the prediction to "No, you don't have the disease" for literally everyone, my model will be 99% accurate!

This is why Accuracy is dangerous for imbalanced datasets. ROC-AUC is much better because it grades the model on how well it distinguishes between the 1% and the 99% using actual probabilities.

The Code Reality

from sklearn.metrics import accuracy_score, roc_auc_score, f1_score

# Note: For accuracy we pass the 0/1 predictions, but for ROC-AUC we pass the PROBABILITIES!
acc = accuracy_score(y_test, y_pred)
auc = roc_auc_score(y_test, y_pred_proba)

print(f"Accuracy: {acc}")
print(f"ROC-AUC: {auc}")

Test Yourself (Concept Drills)

Test your knowledge with essential exam-style concept questions.

Concept check You train a model. Its accuracy on the training set is 98%, but its accuracy on the test set is only 52%. What has happened, and how does this relate to Bias and Variance?

The model is Overfitting. It has memorized the training data (including the noise), but fails to generalize to new, unseen data. This means it has High Variance (and low bias).

True or False To calculate the roc_auc_score in Scikit-Learn, you should pass in the binary predictions (0 or 1).

False! To calculate the ROC-AUC score, you must pass in the probabilities (e.g. y_pred_proba), not the hard 0/1 classes. The ROC curve evaluates how the model performs across all possible probability thresholds.
