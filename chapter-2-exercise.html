Exercise 3: Pandas & The Setup

Imagine you are baking a cake for a competition. You have a giant bowl of raw ingredients (our dataset). Before you even look at the recipe or start sifting flour, you MUST take 30% of your ingredients and lock them in a safe.

Why? Because you need pristine, untouched ingredients to bake the final cake for the judges (the Test Set). If you mix everything together early on, you ruin the test!

In data mining, we always split our data into Training and Testing sets before we do any imputation or scaling. This prevents Data Leakage, where statistics from the test set accidentally influence the training process.

🚨
Exam Trap: The numerical selector

Exams frequently test if you know how to programmatically grab only the numerical columns before doing math operations. The magic function is df.select_dtypes(include=np.number).columns.

# Load the dataset
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split

url = 'https://www.openml.org/data/get_csv/16826755/phpMYEkMl'
df = pd.read_csv(url)

# EXAM TRAP: Programmatically identify numerical columns
numerical_cols = df.select_dtypes(include=np.number).columns.tolist()
print("Numerical cols:", numerical_cols)

# Separate features (X) and target (y)
X = df.drop(columns=['survived'])
y = df['survived']

# The Golden Rule: Split FIRST! (30% test)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

Exercise 4: The Full Pipeline

Now we look at our ingredients. Oh no! Some eggs are missing, and someone wrote "Large" instead of giving us a number of cups of flour.

  • Missing Values: If we are missing a little bit of sugar, we just guess the amount using the average (Mean Imputation). If a whole bag of flour is missing, we throw it away (Drop).
  • Words to Numbers: Computers can't bake with the word "Large". We have to translate it into a number. We create a new label called "Is_Large" and set it to 1 or 0 (One-Hot Encoding).

We replace garbage characters (like ?) with NaN so Pandas recognizes them as missing. Then we impute missing numericals and apply One-Hot Encoding to categorical variables so our ML models can process them.

# Replace garbage '?' with standard NaNs
X_train = X_train.replace('?', pd.NA)
X_test = X_test.replace('?', pd.NA)

# Fill missing numerical values with the mean (fit ONLY on train)
mean_age = X_train['age'].astype(float).mean()
X_train['age'] = X_train['age'].fillna(mean_age)
X_test['age'] = X_test['age'].fillna(mean_age)

# One-Hot Encoding for categorical data (e.g. Sex)
X_train = pd.get_dummies(X_train, columns=['sex'], drop_first=True)
X_test = pd.get_dummies(X_test, columns=['sex'], drop_first=True)
# drop_first=True avoids the Dummy Variable Trap!

Exercise 4 (Cont.): Scaling

We have a problem: Our recipe calls for 1,000 grams of flour, but only 2 teaspoons of baking powder. A robot baker might look at "1,000" and "2" and think flour is 500x more important than baking powder!

To fix this, we Scale everything. We shrink the flour down to a scale of 0 to 1, and we stretch the baking powder to a scale of 0 to 1. Now they are perfectly balanced.

Distance-based algorithms (like K-Means or Neural Networks) are extremely sensitive to the magnitude of features. We must scale them. For exam purposes, the most popular scaler is MinMaxScaler.

🚨
Exam Trap: fit_transform vs transform

You MUST use fit_transform() on the training data to learn the Min and Max. You MUST use transform() on the test data. If you fit on the test data, you just committed Data Leakage.

from sklearn.preprocessing import MinMaxScaler

# Initialize the scaler
scaler = MinMaxScaler()

# 1. FIT and TRANSFORM on the Training Data
numerical_features = ['age', 'fare']
X_train[numerical_features] = scaler.fit_transform(X_train[numerical_features])

# 2. ONLY TRANSFORM on the Test Data
X_test[numerical_features] = scaler.transform(X_test[numerical_features])

Exercise 5: PCA vs t-SNE

Imagine trying to map out a massive 3D city onto a flat 2D piece of paper.

  • PCA (The Mapmaker): Takes a photo from an airplane. It creates a rigid, perfectly mathematical map. If you take the photo twice from the exact same spot, it looks identical every time.
  • t-SNE (The Tourist): Walks around the city and draws a map based on which buildings are next to each other. It's beautiful and colorful, but if they draw it twice, the map might look totally different!

In Sprint Exercise 5, we explored scRNA-seq (Genomics) data with thousands of features. Why run PCA before t-SNE? Because t-SNE gets overwhelmed if you give it too much data. We use PCA to filter out the noise (like stripping away the clouds in the airplane photo), and then we hand that clean, simplified data to t-SNE to draw the final colorful clusters!

In Sprint Exercise 5, we explored scRNA-seq (Genomics) data with thousands of features. We used Dimensionality Reduction to visualize it.

🚨
Exam Trap: Why PCA before t-SNE?

This is a classic question. The official solution notes that PCA is applied first because it: 1. Removes irrelevant variance and noise (improving t-SNE stability) and 2. Reduces computational cost/runtime.

💡
Interpreting the Plots (Q7 Solution)

The PCA plot typically shows a continuous spread without clearly separated groups because it preserves global variance. The t-SNE plot reveals compact clusters because it captures local structure.

🚨 THE 2 MAJOR t-SNE TRAPS:
1. Distance is meaningless: If two clusters are close together, it does NOT mean they are related! The white space is artificially expanded.
2. Size is meaningless: A large spread-out cluster does not mean it has more variance than a tightly packed one.

from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler

# 1. ALWAYS scale before dimensionality reduction
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. PCA: Deterministic, linear, preserves global variance
# We reduce thousands of genes down to the top 50 components
pca_50 = PCA(n_components=50)
X_pca_50 = pca_50.fit_transform(X_scaled)

# 3. t-SNE: Stochastic, non-linear, preserves local neighbors
# We feed the PCA output (X_pca_50) into t-SNE
tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_tsne = tsne.fit_transform(X_pca_50)
