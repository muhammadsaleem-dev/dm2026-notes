Framing: Neural Nets as Generalized Regression

"Neural networks are the generalization of linear regression."

A single artificial neuron (perceptron) — inputs → weighted sum Σwᵢxᵢ + b → activation φ(·) → output — is structurally identical to logistic regression. The reveal the whole chapter builds toward: a perceptron is logistic regression; a neural network is many logistic-regression units stacked and chained.

Classical programming, ML, and DL share the same loop — study problem → (write rules | train on hand-designed features | train on self-learned features) → evaluate → analyze errors → repeat — differing only in where the features come from: hand-written rules, manually engineered features, or features the model discovers itself. A network with one hidden layer is "non-deep"; deep learning starts at 3+ hidden layers (often hundreds).

Linear Regression, Properly

Every neuron's math starts here.

Modelŷ = Xω + b
AssumptionMeaning
LinearityRelationship between X and Y is linear
IndependenceObservations are independent
HomoscedasticityConstant variance of residuals across predicted levels
NormalityErrors are normally distributed
No multicollinearityPredictors aren't highly correlated with each other
Cost function (MSE)J(θ) = (1/2M) · Σᵢ (y⁽ⁱ⁾ − ŷ⁽ⁱ⁾)²

Fitting the model = finding the θ = (ω, b) that minimizes J(θ). Squared error is used instead of absolute error because it's quadratic — error grows faster the further you are from the optimum, which is exactly the shape gradient-based search exploits. Brute-force search (e.g. scanning every possible θ) ignores that structure entirely and is impractical once θ has more than a couple of dimensions.

3

Gradient Descent

The one optimization algorithm everything else in this chapter reuses.

The gradient of a function gives its direction of steepest ascent and how fast it's changing there. Algorithm:

  1. Pick a random initial θ and a learning rate α.
  2. Repeat until convergence: θⱼ ← θⱼ − α · ∂J(θ)/∂θⱼ for every parameter j.
Linear regression gradients (chain rule)∂J/∂b = −(1/M) Σ (y⁽ⁱ⁾ − (ωx⁽ⁱ⁾+b)) ∂J/∂ω = −(1/M) Σ (y⁽ⁱ⁾ − (ωx⁽ⁱ⁾+b)) · xᵀ⁽ⁱ⁾

For a convex problem (linear regression + MSE has only one basin), gradient descent is guaranteed to reach the global minimum — provided the learning rate is chosen well; too large a rate can still cause divergence even on a convex surface.

Learning rate αEffect
Too lowMany tiny steps, slow convergence
Just rightEfficient convergence
Too highOvershoots, oscillates, can diverge

Other linear-model variants

MethodIdea
Polynomial regressionAdds x², x³ terms — non-linear in x, still linear in the parameters
Ridge (L2)Penalizes Σwⱼ² — fights multicollinearity/overfitting, shrinks weights but rarely to zero
Lasso (L1)Can shrink weights to exactly zero → automatic feature selection
Elastic NetCombines L1 + L2, useful when predictors are highly correlated
4

Logistic Regression → One Neuron

Running example throughout: predicting malignant vs. benign from tumor measurements.

Weighted sum + sigmoidz = wᵀx + b ŷ = σ(z) = 1 / (1 + e^−(wᵀx+b))

The sigmoid squashes output into (0,1), read as a class probability; an adjustable threshold converts it to a hard 0/1 label.

Binary cross-entropy costJ(ω,b) = −(1/M) Σᵢ [ y⁽ⁱ⁾ log(ŷ⁽ⁱ⁾) + (1−y⁽ⁱ⁾) log(1−ŷ⁽ⁱ⁾) ]

Via the chain rule (using σ′(x) = σ(x)(1−σ(x))), the gradient collapses to a strikingly simple form:

Gradient (identical shape to linear regression's)∂J/∂ω = (1/M) Σ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · xᵀ⁽ⁱ⁾

More than two classes

  • One-vs-Rest (OvR) — train one separate binary model per class.
  • Softmax regression — softmax(zᵢ) = e^zᵢ / Σⱼ e^zⱼ, turning a score vector into a probability distribution that sums to 1. Example: z = [1.30, 5.10, 2.20, 0.70, 1.10] → softmax ≈ [0.02, 0.90, 0.05, 0.01, 0.02].

Why logistic regression isn't enough

LimitationDescription
Linear boundaries onlyFails on non-linearly-separable data
Limited feature interactionDoesn't capture interactions unless manually engineered
Limited capacityStruggles with complex tasks (image/audio classification)
Sensitive to outliersOutliers disproportionately affect the cost function
ScalabilityWeak on large, high-dimensional data
5

Building the Network

Each hidden unit is now called a neuron — a mini logistic regression whose output feeds the next layer.

Chaining more layers builds a hierarchy of transformations, learning features automatically (e.g. image recognition: edges → contours → parts → whole object) instead of requiring them hand-engineered.

Forward propagation

z^[1] = W^[1]x + b^[1], a^[1] = g^[1](z^[1]) z^[2] = W^[2]a^[1] + b^[2], a^[2] = g^[2](z^[2]) = ŷ ŷ = g^[2]( W^[2] · g^[1](W^[1]x + b^[1]) + b^[2] )

Backpropagation

Gradient descent applied to every layer's parameters, with local gradients propagated backward via the chain rule:

W^[2] := W^[2] − η∇_W[2]J, b^[2] := b^[2] − η∇_b[2]J W^[1] := W^[1] − η∇_W[1]J, b^[1] := b^[1] − η∇_b[1]J At the output layer∇_z[2]J = ŷ − y ∇_W[2]J = (ŷ − y) · a^[1]ᵀ

Notation: ℓ = number of layers · n^[i] = units in layer i (n^[0] = inputs, n^[ℓ] = outputs) · a^[i] = activations of layer i (a^[ℓ] = ŷ) · g^[i] = layer i's activation function · W^[i], b^[i] = layer i's parameters · z^[i] = W^[i]a^[i−1] + b^[i].

Training loop: ① forward propagation (compute ŷ, then cost J) → ② backpropagation (chain-rule gradients, update every parameter) → repeat until convergence or max iterations.

6

Hyperparameters, Activations & Why Deep Training Is Hard

Network size (depth × width) is a hyperparameter fixed before training. Bigger → more capacity, more overfitting risk, more compute; smaller → underfitting risk. Practical advice: start small, grow based on validation performance, add dropout as size grows, use early stopping.

Activation functions

Needed properties: non-linearity (to learn beyond linear relationships), differentiability (backprop requires it), bounded output (stabilizes training), and computational efficiency.

What makes deep nets hard to train

  • Optimization difficulty — vanishing gradients, and getting stuck at saddle points rather than true minima.
  • Overfitting — high-capacity models memorize noise instead of the underlying trend.
  • Training instability — exploding or vanishing gradients destabilize weight updates, especially in deep stacks.
CategoryTechniques
OptimizationRight optimizer (SGD, Adam), learning-rate decay, good weight init, gradient clipping
RegularizationDropout, L1/L2, early stopping, batch/layer normalization
ArchitectureMatch the architecture to the task (CNNs for images, RNNs for sequences)

Gradient Descent at Scale

Full-batch gradient descent doesn't survive contact with real dataset sizes.

Motivating scale problem from the deck: 30,000 features × 1M data points × 1000 training epochs with full-batch gradients ≈ 30 trillion term evaluations — infeasible.

Batch GDStochastic GDMini-Batch GD
Each step usesThe full datasetOne random pointA small batch
Cost curveSmoothHighly fluctuatingMildly fluctuating
ProsExact gradient, ideal for convex problemsFast updates, can escape local minima, memory-efficientStable and fast — best of both
ConsSlow, expensive per stepNoisy, sensitive to outliers—

Learning-rate schedules

Step decay: α = α₀ × factor^(epoch / decay_step) Exponential decay: α = α₀ × e^(−decay_rate × epoch) 1/t decay: α = α₀ / (1 + decay_rate × epoch)

Course guidance: start with Adam for most tasks (works well with little tuning); pair plain SGD with a decay schedule when training very large models for stability; always monitor the cost curve rather than assuming one optimizer fits everything.

Input normalization

μ = (1/M) Σ x⁽ⁱ⁾ σ² = (1/M) Σ (x⁽ⁱ⁾ − μ)² x_normalized = (x − μ) / σ
Rule

μ and σ are computed on training data only and become part of the saved model — reuse the exact same values on test/production data (see Ch.2 §2 for the same rule applied to scikit-learn scalers).

Closing recipe

  1. Choose a framework
  2. Build the model (size, normalization, dropout, …)
  3. Define the cost function
  4. Select an optimizer and learning rate
  5. Apply backpropagation
  6. Tune hyperparameters

"Neural networks are the second-best way to do everything" — a specialized method often beats a generic NN for any one task, but a NN is a strong fallback when nothing more specialized fits.
