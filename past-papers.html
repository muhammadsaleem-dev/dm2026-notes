5 Golden Rules to Ace the Exam

Avoid the pitfalls that cost students full points on automated test runners.

🚨 1. Never Hardcode Global Variables

When writing a function like def find_num(Dataframe):, always use the parameter name (Dataframe), never the test dataframe X from the outer scope! The grading script evaluates with unseen test data.

🎯 2. Follow Exact Output Formatting

If the question asks for "≤ 2 words" (e.g. technique = "PCA"), do not write full sentences like "We should use PCA because...". Automated grading checks exact string matches!

📊 3. Fit on Train Only, Transform Both

When scaling with MinMaxScaler or encoding with OneHotEncoder: scaler.fit_transform(X_train), but strictly scaler.transform(X_test) to prevent data leakage!

📐 4. Permutation Importance Scoring

For regression tasks (like Remaining Useful Life RUL), permutation_importance requires a metric where higher is better. Use neg_mean_squared_error or r2, never raw positive MSE!

🔍 5. Greedy Decoding is Just Argmax

Greedy decoding selects the token index with the maximum logit value. You don't even need to compute softmax to find the greedy token index!
