Dimensionality Reduction

The Curse of Dimensionality
PCA → t-SNE → Visualization

When you only have 2 features (like Age and Income), you can easily plot them on a scatterplot. But what happens when you have a dataset with 5,000 features? How do you visualize a 5,000-dimensional graph? You squash it.

High-Level Overview

Our concrete running example: Single-Cell RNA Sequencing (scRNA-seq).

The PBMC3k Dataset

In the Titanic dataset, we only had a few features. But in Biology, a single human immune cell might have thousands of genes expressed! We have a dataset where each row is a single cell, and there are thousands of columns (features) representing gene expressions. Visualizing this is impossible for humans.

The Goal

We want to squash these thousands of dimensions down to just 2 dimensions, so we can plot them on a standard X-Y graph and see if the different immune cells naturally form distinct clusters.

1

PCA (Principal Component Analysis)

PCA is a Linear technique. It looks at the global structure of the data and creates new orthogonal axes (Principal Components) that maximize variance.

The Code Reality

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# Step 1: ALWAYS standardize your data before PCA! 
# (Otherwise, genes with naturally huge numbers will dominate the variance)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X) # X has 5000 columns

# Step 2: Apply PCA to squash it down to 50 dimensions
pca = PCA(n_components=50)
X_pca_50 = pca.fit_transform(X_scaled) 

# X_pca_50 now only has 50 columns! But it retains most of the original information.
2

t-SNE (t-Distributed Stochastic Neighbor Embedding)

PCA is great for preserving global structure, but it is terrible at separating complex, non-linear clusters (like a spiral shape). t-SNE is a Non-Linear technique that excels at preserving local neighborhoods. If two cells are similar in high-dimensional space, t-SNE forces them to be right next to each other in 2D space.

Perplexity

A crucial t-SNE parameter. Think of it as "how many close neighbors each point considers". A low perplexity (e.g. 2) focuses purely on tiny local clusters, making the graph look like scattered dots. A higher perplexity (e.g. 30-50) considers broader regions. You must experiment with this!

Random Seed

t-SNE is stochastic (random). If you run it 3 times without setting a random_state, the 2D plot will look completely different every time (even though the topological meaning remains the same). Always set a random seed!

💡
Cheat Sheet: PCA vs t-SNE

Memorize this exact table for the exam!

Feature PCA t-SNE
Nature Linear Non-Linear
Preserves Global Structure (Variance) Local Structure (Neighborhoods)
Determinism Deterministic (Always the same) Stochastic (Randomized)
3

Why apply PCA before t-SNE?

If we want a 2D plot, why not just run t-SNE directly on the 5,000-dimensional data?

  • Speed: Computing distances between points in 5,000 dimensions is painfully slow.
  • The Curse of Dimensionality: In incredibly high dimensions, distance metrics (like Euclidean distance) start to lose their meaning. Everything seems equally far apart!
  • Noise Reduction: PCA strips away the random noise in the data.

The Golden Pipeline: Use PCA to squash the data from 5,000D to ~50D (removing noise and speeding things up). THEN, use t-SNE to squash the 50D data down to 2D for beautiful cluster visualization!

The Code Reality

from sklearn.manifold import TSNE
import matplotlib.pyplot as plt

# Step 3: Run t-SNE on the 50D PCA data (NOT the raw 5000D data!)
# We set perplexity to 30, and random_state so it looks the same tomorrow.
tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_tsne_2 = tsne.fit_transform(X_pca_50)

# Step 4: Visualize!
# X_tsne_2 has exactly 2 columns: The X coordinate, and the Y coordinate.
plt.scatter(X_tsne_2[:, 0], X_tsne_2[:, 1])
plt.title("t-SNE visualization of Immune Cells")
plt.show()

Test Yourself (Concept Drills)

Test your knowledge with essential exam-style concept questions.

Name it You need to visualize your high-dimensional dataset in 2D. You want to preserve local neighborhoods, you suspect the data is highly non-linear, and you don't care if the result is stochastic. Which algorithm do you choose?

t-SNE! It is non-linear, stochastic, and focuses on preserving local structures for visualization. PCA is linear, deterministic, and preserves global variance.

Concept check You run t-SNE on your data and the plot looks like tiny, separated groups of 2 or 3 dots scattered randomly everywhere. What parameter is likely set incorrectly?

Perplexity is too low. A very low perplexity (e.g., 2) forces the algorithm to only care about its absolute closest neighbors, destroying the broader structure of the clusters.

Concept check Why is PCA commonly applied before t-SNE on high-dimensional data?

1. Speed: t-SNE is computationally expensive in high dimensions.
2. Noise Reduction: PCA filters out the noise, keeping only the variance that matters.
3. Distance Metrics: Distance calculations break down in extreme dimensions (Curse of Dimensionality), so reducing to ~50D helps t-SNE calculate true local neighborhoods.
