Explainability & Causality (intro)

Why did the computer make that guess? Let's ask it!

1. The Analogy Recap

Glass Box vs. Black Box: A Decision Tree is a Glass Box. It's like a clear piggy bank—you can see exactly how every coin gets sorted! A Random Forest is a Black Box. It's like a magic vending machine—you put a coin in, and a snack comes out, but you have no idea how it works inside! To understand the vending machine, we need special tools called Explainable AI (XAI).

Key Terms

  • Explainable AI (XAI): Detective tools we use to figure out why a Black Box model made its guess.
  • Feature Importance: Figuring out which clues (features) the model cares about the most.
  • Glass Box Models: High Explainability (Decision Trees, Linear/Logistic Regression, Naive Bayes, k-NN).
  • Black Box Models: High Accuracy, Low Explainability (Random Forests, Neural Networks, Gradient Boosted Models).
  • SHAP: A super-smart math tool that tells us exactly how much each clue changed the final guess (like figuring out that adding cheese to a burger added exactly $1.50 to the price).

2. The Code Reality

Python (SHAP) 
# Black-box models (like Random Forests) need external detective tools like SHAP
import shap

# We bring in our detective (TreeExplainer) to investigate the Black Box (clf)
explainer = shap.TreeExplainer(clf)

# We ask the detective to explain the new toys (X_test)
shap_values = explainer.shap_values(X_test)

# Built-in way to check Feature Importance without SHAP
importances = clf.feature_importances_
Quick Example: Glass vs Black Box

If a game tells you "You Lose!", you want to know why.

  1. Glass BoxA Decision Tree is totally transparent. It says: "You lost because you jumped too late AND you had no power-ups."
  2. Black BoxA Random Forest is opaque. It just says "You Lose." We have to use a detective tool like SHAP to figure out that jumping late caused 80% of the loss.
🚨 Common Pitfall

Knowing a clue is "important" (like the Blindfold Test) is only half the battle. It tells you the clue matters, but it does NOT tell you if it's a good thing or a bad thing! For Directional Feature Impact, you must use methods like Partial Dependence Plots (PDP) or SHAP.

💡 Key Concept

When doing the Blindfold Test (permutation importance), the scoring function must match the game you are playing. If you are predicting classes (classification), we score by accuracy. But if you are predicting a number—like the Remaining Useful Life (RUL) of a toy car battery—you must use a number-scoring metric like neg_mean_squared_error or r2.

3. Exam Cheat Sheet

  • Glass-box vs Black-box: Decision Trees are clear (glass-box). Random Forests are secret (black-box).
  • Explainable AI (XAI): Answers "What clues did the computer use to guess?" (e.g., Feature Importance, SHAP).
🎓 Technical Notes

7. Explainable AI (XAI) and Causal AI

In high-stakes environments, "Black box" models—which offer high accuracy but low transparency—can be problematic. XAI and Causal AI seek to bridge this gap.

Bottom Line: Explainable AI is crucial in fields like healthcare and finance. It highlights the specific symptoms or risk factors used in a decision, allowing professionals to validate the logic and empowering patients or clients to make informed choices.

Glass Box vs. Black Box Models:

  • Glass Box (High Explainability): Linear/Logistic Regression, Naive Bayes, Decision Trees, k-Nearest Neighbor.
  • Black Box (High Accuracy): Neural Networks (CNN, RNN), Random Forests, Gradient Boosted Models.

Key Definitions:

  • Model Interpretability: Understanding the internal logic of the model.
  • Feature Importance: Identifying which features (e.g., Age vs. Income) most influenced the prediction. In Scikit-Learn, this is accessed via the feature_importances_ attribute.
  • Causal AI: Moves beyond correlation to identify cause-and-effect relationships (e.g., "Does smoking cause the cancer?").

8. Practical Implementation (Scikit-Learn)

Implementing these models in Python requires careful parameter tuning to balance complexity and accuracy.

from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

# Decision Tree Implementation
# criterion="entropy": Use Information Gain logic for splitting.
# min_samples_leaf=3: A regularization parameter to prevent overfitting 
# by ensuring a leaf node doesn't become too specific to a few samples.
clf = DecisionTreeClassifier(criterion="entropy", min_samples_leaf=3)
clf.fit(X, y)

# Random Forest Implementation
# n_estimators=20: Builds 20 parallel trees to vote on the outcome.
clf_rdf = RandomForestClassifier(n_estimators=20)
clf_rdf.fit(X, y)

# Accessing Feature Importance (XAI)
importances = clf_rdf.feature_importances_

Technical Note: Scikit-Learn classifiers require numerical attributes. Categorical data must be processed using OneHotEncoder or LabelEncoder.
