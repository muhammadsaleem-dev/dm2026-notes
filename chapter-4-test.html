Test Yourself

Retrieval practice — the single best-evidenced study technique there is.

Why must features be scaled (e.g., Z-score) before applying K-Means?

Because K-Means uses Squared Euclidean Distance. If 'Income' ranges in the thousands and 'Age' ranges in the tens, the Income feature will completely mathematically dominate the distance calculation, causing K-Means to essentially ignore Age.

Explain the "Risk of Local Optima" in K-Means and how to fix it.

Because K-Means initializes with random seeds, a bad initial placement can trap the greedy algorithm in a mathematically stable but incorrect clustering. The standard solution is running the algorithm multiple times from scratch (n_init) and keeping the run that resulted in the lowest total inertia (WCSS).

What is the Gap Statistic, and why is it preferred over the Elbow Method?

The Elbow Method relies on a subjective visual interpretation of a "bend" in the inertia graph, which lacks theoretical rigor. The Gap Statistic is a robust statistical approach that compares the log-dispersion of your real data against the dispersion of simulated, uniform "null" data to find a statistically significant value for K.

What happens if you run K-Means on data shaped like a crescent moon or a "U"?

K-Means will fail and split the shape incorrectly. This is called Geometric Bias. Because K-Means uses Euclidean distance, it inherently assumes all clusters are spherical (Gaussian). It cannot trace non-convex shapes or anisotropic (stretched) blobs.

What does "RFM" stand for, and why is it used before clustering?

Recency, Frequency, Monetary. It is a feature engineering framework used to aggregate massive amounts of raw transaction logs into three distinct behavioral metrics per customer. You cannot easily cluster raw transaction logs; you must cluster customer profiles.

Can K-Means be used effectively on categorical (nominal) data?

No. Euclidean distance is mathematically meaningless for categorical labels (e.g., "Red", "Blue", "Green"). For categorical datasets, algorithms like K-Modes or metrics like Gower distance should be used instead.
