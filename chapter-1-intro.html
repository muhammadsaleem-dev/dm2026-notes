What Is Data Mining?

An interdisciplinary field, not a single technique.

Data mining uses scientific methods, processes, algorithms, and systems to extract knowledge and insight from structured and unstructured data across a broad range of application domains.

Data science sits at the intersection of three fields:

  • Computer Science ∩ Math & Statistics → Machine Learning
  • Math & Statistics ∩ Domain Knowledge → Empirical Research
  • Computer Science ∩ Domain Knowledge → Software Development
  • All three overlapping → Data Science
"Data Scientist (n.): Person who is better at statistics than any software engineer and better at software engineering than any statistician." — Josh Wills

The Project Lifecycle

Cyclical, not a strict waterfall — every stage routes through a shared data store.

Problem understanding→ Explore & process→ Modelling & analysis→ Communicate results→ Deploy & operationalize→ Test & monitor ↺ back to the data store

The deck presents this cycle three separate times, always identical — the recurring point being that a project may involve all or only some of these stages, revisited as needed rather than executed once in order.

Rule

Domain knowledge runs through the whole cycle: it guides preprocessing, shapes modelling decisions, and provides the context needed to explain results. "Always dive into the domain behind the data — it's the key to engineering meaningful features, focusing your analysis, and telling a story your audience understands."

3

Data Representation

To train a model, data must become an informative, numerical representation — and the same signal often has more than one valid encoding.

  • Text → TF-IDF: Term Frequency (how often a word appears within a document) × Inverse Document Frequency (how rare that word is across the corpus) — weights words by local importance, discounted by how common they are everywhere.
  • Text → Word embeddings (Word2Vec, GloVe): map words into a continuous vector space where semantically similar words sit close together; can be pre-trained on large corpora.
  • Images → raw pixel values.
  • Molecules / graphs → graph representation (atoms = nodes, bonds = edges), or learned node embeddings (Node2Vec) that capture structural/network information as continuous vectors.
  • Audio → Spectrogram: converts a waveform into a visual frequency-over-time representation, useful for speech/music analysis — though the same signal can also be modeled directly as a 1-D time series.

There is rarely one "correct" representation — the right one depends on the downstream task and what structure you need to preserve.

Types of Data & Core Tasks

The vocabulary used to describe every dataset and every problem type in the rest of the course.

By measurement scale

  • Qualitative / Categorical — Nominal (no order: gender, hair color) or Ordinal (ordered: reviews, grades, status)
  • Quantitative / Numerical — Discrete (countable: number of students) or Continuous (measurable: height, speed, weight)

By structure

TypeDefinitionExamples
StructuredOrganized data adhering to a predefined schemaCustomer tables, transaction records
UnstructuredNo predefined format; harder to processEmails, videos, social posts
Semi-structuredNo relational schema, but has organizational tags/markersJSON, XML, graph data

Core task types

TaskDescription
ClassificationSorting data into predefined categories (e.g. spam detection)
Association analysisIdentifying relationships between items in large datasets
RegressionPredicting continuous values (e.g. stock prices, recovery time)
ClusteringGrouping data by similarity without predefined labels
OptimizationFinding the best solution within constraints
RecommendationSuggesting items/content based on preferences
Anomaly detectionIdentifying unusual patterns or outliers
PersonalizationTailoring user experiences or interactions
Decision supportInforming decisions via analysis of large datasets
SimulationModelling complex systems to predict behavior
Text miningUnderstanding, mining, or generating human language

Communicating Results & Tooling

A model is only useful once its results are understood — and built with the right tools.

Storytelling with data rests on three components: Data (the evidence), Visualization (charts/dashboards), and Narrative (what happened, why, what now). Common chart types: text/big-number, table, scatterplot, line, heatmap/slopegraph, bar (vertical/horizontal/stacked), waterfall, square-area chart.

CategoryPython tools
Core / generalNumPy, Pandas, Matplotlib, Seaborn
Machine learningScikit-learn, XGBoost, RAPIDS
Big dataApache Spark (PySpark)
Large language modelsHugging Face Transformers, OpenAI GPT
Deep learningTensorFlow, PyTorch
Hyperparameter optimizationOptuna, Hyperopt, GridSearchCV
