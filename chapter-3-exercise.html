Sprint Exercise: Cancer Classification

Welcome to the project! Let's build a real-world medical diagnostic engine.

The Mission

Imagine you just got hired as a Data Scientist at a cancer research hospital. The chief pathologist hands you a massive file containing measurements of cell nuclei (radius, texture, perimeter) for hundreds of patients.

"We need a machine learning model that can instantly predict if a tissue sample is cancerous or healthy based on these cell sizes," he says. "Can you build this pipeline for us?"

🎯 What this Exercise Covers
  • 🧹 Data Cleansing: Handling Impossible Dates & Negative Sizes
  • ✂️ Data Splitting: Hiding the Test Set
  • 📊 Outlier Detection: The IQR Method
  • 🌲 Random Forest: Configuring the Algorithm
  • 🧪 Evaluation: Reading a Confusion Matrix

Since we have labels ("Cancerous" or "Healthy"), this is a Classification problem! Let's walk through exactly how we solve this, step-by-step.

Step 1: Taking out the Trash

If you look closely at the hospital records, some are totally broken. Some patients were "treated" before they were even "diagnosed" (time travel!). And some cell sizes are "Negative" (you can't have a negative size!). If we feed these into our algorithm, it's going to get very confused! So, our very first step is to erase these impossible numbers.

Step 2: Hiding the Test Set

Before we fix anything else, we must hide 25% of the patient records in a locked closet (our Test Set). The Random Forest is NOT allowed to see them until the very end! If it sees them early, it will just memorize the answers instead of actually learning how to diagnose cancer.

Step 3: Fixing the Weird Cells (Outliers)

Sometimes a cell size is listed as the size of a basketball. That's a typo from the doctors! We use a math trick called the IQR (Interquartile Range) to spot these crazy mistakes and delete them.

How to read this: Boxplots spot mistakes! The colored box is the "normal" cells. Any black dot floating way above the box is an impossible typo we need to delete.

Step 4: The Game Plan

Instead of guessing how to fix the missing data, we write down our entire game plan before we even start. We decide to use a StandardScaler (a shrink ray that makes all cell sizes fair) and we configure our Random Forest.

Step 5: The Final Exam

We train our Random Forest, and then we unlock the closet and force it to diagnose the hidden patients. We grade it using a Confusion Matrix.

How to read this: This is a scorecard! The bright yellow square (Top-Left) means our algorithm correctly guessed a healthy patient. The teal square (Bottom-Right) means it correctly caught the cancer!

🎓 Technical Tutorial: Cancer Classification Pipeline

Welcome to the technical walkthrough. Today we are building an end-to-end supervised learning pipeline using clinical data. Our goal is to transform raw, unstructured measurements into an accurate Random Forest classifier.

1. Global Configuration

A good pipeline is driven by a configuration dictionary, allowing us to easily swap out strategies without rewriting core logic.

# Configuration dictionary to track preprocessing and modeling choices
config = {
    "missing_value_strategy": "replace_by_mean_cancer_type",
    "scaling_method": "StandardScaler",
    "RDF": {"n_estimators": 1000,
            "max_depth": 6,
            "min_samples_split": 2,
            "min_samples_leaf": 2,
            "max_features": 0.7,
            "class_weight": 'balanced'}
}

# Set global random seed for reproducibility
import numpy as np
RANDOM_STATE = 42
np.random.seed(RANDOM_STATE)

2. Data Cleansing: Garbage In, Garbage Out

If you feed raw measurements into an algorithm, you will predict noise. Here is how we clean it up:

  • Wrong formats: We force string representations into numeric values using pd.to_numeric(errors='coerce').
  • Logical impossibilities: A treatment date cannot precede a diagnose date. We calculate the difference, fix the ages, and drop the dates.
  • Negative Numbers: Measurements like texture_0 cannot be negative. We replace them with np.nan.
import pandas as pd

data = pd.read_csv('./data.csv', header='infer')

# Force to numeric
data['texture_2'] = pd.to_numeric(data['texture_2'], errors='coerce')

# Fix impossible dates
data['diagnose_date'] = pd.to_datetime(data.diagnose_date)
data['treatment_date'] = pd.to_datetime(data.treatment_date)
mask = data['treatment_date'] > data['diagnose_date']
year_diff = data.loc[mask, 'treatment_date'].dt.year - data.loc[mask, 'diagnose_date'].dt.year
data.loc[mask, 'age'] -= year_diff
data.drop(['treatment_date', 'diagnose_date'], axis=1, inplace=True)

# Replace physically impossible negative values with NaN
data.loc[data.texture_0 < 0, 'texture_0'] = np.nan
data.loc[data.texture_2 < 0, 'texture_2'] = np.nan

3. Train/Test Split

Here is where most junior data scientists fail: You MUST split your data before applying Imputation or Scaling! If you scale the entire dataset before splitting, information from the test set "leaks" into the scaler's mean/variance calculations, ruining the integrity of your evaluation.

from sklearn.model_selection import train_test_split

features_list = ['radius_0', 'texture_0', 'perimeter_0', 'radius_1', 'texture_1',
                 'perimeter_1', 'radius_2', 'texture_2', 'perimeter_2', 'age']

X_train, X_test, y_train, y_test = train_test_split(
    data[features_list], 
    data['cancer_type'],
    test_size=0.25, 
    random_state=RANDOM_STATE
)

4. Outlier Detection (IQR Method)

We use the IQR (Interquartile Range) method to detect outliers, and replace them with NaN so our Imputer can handle them later.

Visual Output: Outlier Detection

How to read this: The boxplots reveal massive outliers in features like perimeter_0 and perimeter_2. Any dots floating above the whiskers are considered statistically anomalous and will be removed. 
# Define the threshold for outlier detection
k = 1.5

# Compute Q1, Q3, and IQR using ONLY THE TRAINING DATA!
Q1 = X_train.quantile(0.25)
Q3 = X_train.quantile(0.75)
IQR = Q3 - Q1

# Create a mask identifying outliers
outlier_mask_train = (X_train < (Q1 - k * IQR)) | (X_train > (Q3 + k * IQR))
outlier_mask_test = (X_test < (Q1 - k * IQR)) | (X_test > (Q3 + k * IQR))

# Replace outliers with NaN
X_train = X_train.where(~outlier_mask_train, np.nan)
X_test = X_test.where(~outlier_mask_test, np.nan)

5. Imputation & Scaling

We dynamically execute the strategies we defined in our config dictionary.

from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, RobustScaler, Normalizer, MinMaxScaler

# 1. IMPUTATION
if config['missing_value_strategy'] == 'replace_by_mean_cancer_type':
    imp = SimpleImputer(missing_values=np.nan, strategy='mean')
imp.fit(X_train)  # Fit on training data ONLY
X_train = imp.transform(X_train)
X_test = imp.transform(X_test)

# 2. SCALING
if config['scaling_method'] == 'StandardScaler':
    scaler = StandardScaler()
scaler.fit(X_train)  # Fit on training data ONLY
X_train = scaler.transform(X_train)
X_test = scaler.transform(X_test)

X_train = pd.DataFrame(X_train, columns=features_list)
X_test = pd.DataFrame(X_test, columns=features_list)

6. Random Forest Classification

We initialize the model using our config, fit it to our clean training data, and generate predictions on the test data.

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, confusion_matrix, ConfusionMatrixDisplay
import matplotlib.pyplot as plt

clf = RandomForestClassifier(
    n_estimators=config["RDF"]["n_estimators"], 
    max_depth=config["RDF"]["max_depth"],
    min_samples_split=config["RDF"]["min_samples_split"],
    min_samples_leaf=config["RDF"]["min_samples_leaf"],
    max_features=config["RDF"]["max_features"],
    class_weight=config["RDF"]["class_weight"],
    random_state=RANDOM_STATE
)

clf.fit(X_train, y_train)
y_predict = clf.predict(X_test)

# Print metrics
print(classification_report(y_test, y_predict, target_names=['healthy','cancer']))

# Plot Confusion Matrix
cm = confusion_matrix(y_test, y_predict)
disp = ConfusionMatrixDisplay(confusion_matrix=cm, display_labels=clf.classes_)
disp.plot()
plt.show()

Visual Output: Confusion Matrix

How to read this: A Confusion Matrix visualizes True Positives, True Negatives, False Positives, and False Negatives.

• Top-Left: Healthy patients correctly identified as healthy.
• Bottom-Right: Cancerous patients correctly identified as cancerous.

7. Productionizing (The Final Refit)

To maximize predictive power before deployment, combine the datasets to train on 100% of available data.

# Combine train and test data back together
X_all = pd.concat([X_train, X_test], axis=0).reset_index(drop=True)
Y_all = pd.concat([y_train, y_test], axis=0).reset_index(drop=True)

# Retrain the model on everything
clf.fit(X_all, Y_all)
