Sprint Exercise: The Full Pipeline

Playing cell detective with a Random Forest from start to finish!

In this exercise, we are predicting a cancer_type by looking at clues inside a cell. But before our Random Forest can make any guesses, we have to clean up a massive mess! Think of the dataset like a messy playroom.

Step 1: Cleaning the Messy Room (Data Cleaning)

First, we find broken toys and weird items that don't belong:

  • Wrong formats: Some numbers were written as words! We convert them back to numbers.
  • Time travel mistakes: Some cells were "treated" before they were "diagnosed." We fix the ages and throw away those dates because they confuse the detective!
  • Impossible things: We found negative sizes (you can't have a negative size!). We erase them and mark them as missing (NaN).

Step 2: Splitting the Toys (Train vs Test)

Before we fix everything else, we hide 20% of the toys (the test set) in a closet. The detective is NOT allowed to see them until the very end!

Step 3: Fixing the Weird Toys (Outliers & Missing Data)

Sometimes a cell size is listed as the size of a basketball. That's a mistake! We use a math trick called the IQR (Interquartile Range) to spot these crazy mistakes. Then, we fill in all the missing gaps (imputation) so the detective has complete files.

Step 4: The Game Plan (Config Dictionary)

Instead of guessing how to fix the toys, we write down our entire game plan before we even start. This is our config dictionary!

Python (Config Dict) 
# Our Game Plan!
config = {
    'missing_value_strategy': 'median',
    'scaling_method': 'standard',
    # We hire 1000 kids for our forest, and tell them to only ask 6 questions max!
    'RDF': {'n_estimators': 1000, 'max_depth': 6, 'class_weight': 'balanced'} 
}

Step 5: The Final Refit (Exam Trap!)

After we test our detective and give them a final grade (using a Confusion Matrix), we let them look at ALL the toys (train + test) one last time to make them as smart as possible for the real world! But remember: once they look at the test toys, they've seen the answers. You can never test them again!

🎓 Technical Notes: Exercise 6 Pipeline

Instead of just describing the steps, here is the concrete Python code from the solution notebook to execute the end-to-end classification pipeline.

1. Data Cleaning (Pandas)

Real-world datasets contain formatting errors and impossible values that must be corrected before modeling.

# Convert strings to numeric, forcing unparseable text to NaN
data['texture_2'] = pd.to_numeric(data['texture_2'], errors='coerce')

# Parse dates and calculate age mathematically
data['diagnose_date'] = pd.to_datetime(data.diagnose_date)
data['treatment_date'] = pd.to_datetime(data.treatment_date)

# Replace physically impossible negative values with NaN
data.loc[data.texture_0 < 0, 'texture_0'] = np.nan

# Drop columns irrelevant to the target classification
data.drop(['treatment_date', 'diagnose_date'], axis=1, inplace=True)

2. Train/Test Split

Split the data before applying imputation or scaling to strictly prevent data leakage.

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, Y, test_size=0.2, random_state=42)

3. Outlier Detection & Imputation

Use the Interquartile Range (IQR) to detect and nullify outliers, then impute all missing values.

# 1. IQR Outlier Detection
Q1 = X_train.quantile(0.25)
Q3 = X_train.quantile(0.75)
IQR = Q3 - Q1
k = 1.5 
lower_bound = Q1 - k * IQR
upper_bound = Q3 + k * IQR

# 2. Imputation and Scaling
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler

imputer = SimpleImputer(strategy='median')
scaler = StandardScaler()

X_train_clean = scaler.fit_transform(imputer.fit_transform(X_train))
X_test_clean = scaler.transform(imputer.transform(X_test)) # Note: transform ONLY

4. Modeling & Evaluation

Use the predefined config dictionary to instantiate and evaluate the Random Forest.

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, confusion_matrix

clf = RandomForestClassifier(**config['RDF'])
clf.fit(X_train_clean, y_train)
y_pred = clf.predict(X_test_clean)

print(classification_report(y_test, y_pred))
# Visualizing False Positives vs False Negatives
ConfusionMatrixDisplay(confusion_matrix(y_test, y_pred)).plot()

5. Productionizing (The Final Refit)

To maximize predictive power before deployment, combine the datasets to train on 100% of available data.

import pandas as pd

# Combine train and test data back together
X_all = pd.concat([X_train, X_test], axis=0).reset_index(drop=True)
Y_all = pd.concat([y_train, y_test], axis=0).reset_index(drop=True)

# Retrain the model on everything
clf.fit(X_all, Y_all)
# Rule: The model can NEVER be evaluated against X_test again!
