High-Level Overview

What is Pandas, and why are we using it?

The Spreadsheet Analogy

Think of Pandas as Excel on steroids, but operated via Python code instead of clicking a mouse. A DataFrame is the entire spreadsheet (rows and columns). A Series is a single column pulled out of that spreadsheet.

Why do we need it?

Raw data is messy. Scikit-learn (our ML library) expects a pristine grid of numbers with no missing values, no strings (like "Mr." or "Male"), and no unnecessary clutter. Pandas is the knife we use to chop, clean, and organize the raw ingredients before handing them to the ML chef.

Pandas Objects & Indexing

How to grab exactly the data you want from the massive table.

1. Key Terms

DataFrame

A 2-dimensional table of data with rows and columns. (e.g. df = pd.DataFrame(data)).

Series

A 1-dimensional array. If you grab one column from a DataFrame, it is returned as a Series. (e.g. df['Age']).

.loc (Label-based)

Finds rows based on their actual name/label in the index (like finding a house by its street address).

.iloc (Integer-based)

Finds rows based on their numerical position starting at 0, regardless of what they are named (like finding the 5th house on the block).

2. The Code Reality

import pandas as pd
import seaborn as sns

# 1. Loading Data
df = sns.load_dataset('titanic')

# 2. Selecting Columns
age_series = df['age']          # Returns a Series
age_fare_df = df[['age', 'fare']] # Returns a DataFrame (note the double brackets!)

# 3. Indexing (loc vs iloc)
first_row_by_pos = df.iloc[0]       # Grabs the 1st row (position 0)
specific_row = df.loc['Saleem']     # Grabs the row where the index label is 'Saleem'

# 4. Filtering (Boolean Indexing)
# Select the first 5 rows where passengers are female
female_passengers = df[df['sex'] == 'female'].head(5)
children = df[df['age'] < 18]

Data Cleaning (NaNs & Features)

Dealing with missing data and broken formats.

1. Key Concepts

NaN (Not a Number)

Represents missing data. If you feed NaNs into most ML models, they crash immediately.

Dropping vs Imputing

If a column is 90% missing, just drop it. If it's only 5% missing, impute (fill) it with the median/mean so you don't lose the rest of the row's valuable data.

Vectorized Operations

Applying a function to an entire column at once, which is 100x faster than writing a Python for loop.

2. The Code Reality

# 1. Finding missing values
missing_percentages = df.isna().mean() * 100

# 2. Replacing garbage values with NaNs so Pandas recognizes them
df = df.replace('?', pd.NA)

# 3. Dropping useless or redundant columns
# (e.g. keeping only the first cabin if multiple are listed)
df = df.drop(columns=['deck', 'embark_town'])

# 4. Vectorized Feature Engineering (Regex)
# Extract titles (Mr., Mrs., Miss.) from a messy Name column
df['Title'] = df['Name'].str.extract(' ([A-Za-z]+)\.', expand=False)

# 5. Type Casting
# Convert a column that looks like strings into usable floats
df['fare'] = df['fare'].astype(float)

Exploratory Data Analysis (EDA)

Understanding the shape, spread, and secrets of your data.

1. Key Concepts

Cardinality

The number of unique values in a categorical column. A column with 2 unique values (Gender) has low cardinality. A column with 10,000 unique values (User_ID) has high cardinality and is usually useless for ML.

Grouping

Splitting the data into buckets (e.g., by Class), applying math to each bucket (e.g., Mean Age), and gluing the results back together.

2. The Code Reality

# 1. Cardinality & Unique Values
unique_counts = df.nunique()        # How many unique values per column?
embarked_values = df['embarked'].unique() # List the actual unique values

# 2. Value Counts
# What percentage of people survived?
survival_rates = df['survived'].value_counts(normalize=True)

# 3. Groupby Aggregation
# Calculate mean age per gender and class
mean_age_by_group = df.groupby(['sex', 'class'])['age'].mean()

# 4. Creating New Features based on math
# Add a column for fare paid per year of age
df['fare_per_age'] = df['fare'] / df['age']

Test Yourself (Concept Drills)

Test your knowledge with essential exam-style concept questions.

Code check You want to grab the row labeled "Index_42". Which command is correct: df.iloc['Index_42'] or df.loc['Index_42']?

df.loc['Index_42']. Use .loc when referencing specific string labels in the index. Use .iloc when you just want a numerical position (like "row number 5").

Concept check A categorical column "Passenger_Name" has 891 unique values across 891 rows. Is this high or low cardinality? Should you One-Hot Encode it?

Extremely High Cardinality. You should NOT One-Hot Encode it, because it would create 891 new columns (one for each passenger). You should either drop the column entirely, or extract a lower-cardinality feature from it (like extracting just the Title: Mr/Mrs/Miss).

Code check How do you filter a DataFrame df to only show passengers who paid a fare greater than $50?

df[df['fare'] > 50]
